# HiveFest10 Image Generator

This project is a web application that allows users to upload an image and overlay it with a selection of themed frames, including HiveFest10 and Polaroid Instax Mini HF10 styles. The application is responsive and user-friendly.

## Project Structure

- **index.html**: Main HTML document for the app.
- **css/styles.css**: Styles for layout, responsiveness, and theming.
- **js/main.js**: Handles image upload, cropping, frame selection, and image generation.
- **frames/**: (If used) Contains local frame images. Most frames are loaded via external URLs.

## Features

- Upload an image via file selection, drag-and-drop, or clipboard paste.
- Crop the uploaded image before applying a frame.
- Choose from multiple HiveFest10 and Instax Mini HF10 frames (over 8+ frames per style).
- Generate a final image with the selected frame.
- Download the generated image or copy it to the clipboard.
- Switch between HiveFest10 and Instax HF10 modes.

## Usage

1. Open `index.html` in a web browser.
2. Use the navigation to select either **HiveFest10** or **Polaroid Instax HF10** mode.
3. Upload an image using the upload button, drag-and-drop, or paste (Ctrl+V).
4. Crop the image as needed.
5. Select a frame from the available options.
6. Click "Generate" to create the final image.
7. Download the image or copy it to the clipboard.
