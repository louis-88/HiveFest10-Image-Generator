# image-overlay-app

This project is a Single-File Application that allows users to upload an image and overlay it with a selection of frames. The application is designed to be responsive and user-friendly.

## Project Structure

- **index.html**: The main HTML document that sets up the structure of the application.
- **css/styles.css**: Contains styles for the application, ensuring a modern look with responsive design.
- **js/main.js**: Handles the image upload functionality, frame selection, and final image generation.
- **frames/leaves_01.png**: The first frame image available for users to overlay on their uploaded image.

## Features

- Users can upload an image.
- Users can select from 10 different frames (currently includes leaves_01.png).
- Users can generate a final image that combines their uploaded image with the selected frame.
- Options to download the generated image or copy it to the clipboard.

## Color Scheme

The application uses the following color codes for its design:
- #F5DEB3
- #e88f2c
- #d0372a
- #1f5034
- #0a473f

## Usage

1. Open the `index.html` file in a web browser.
2. Upload an image using the provided upload button.
3. Select a frame from the available options.
4. Click on "Generate HiveFest Style Image" to create the final image.
5. Download the generated image or copy it to the clipboard.
